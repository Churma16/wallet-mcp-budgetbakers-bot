# Issue #137 parity note

This bounded migration ports the eight legacy core utility/parsing/validation/localization suites to native Vitest without changing production behavior.

The migrated suites preserve the existing numbered scenario groups and edge-case coverage while replacing top-level executable assertions with named Vitest cases where the legacy suite did not already use a test runner. Deterministic time fixtures are used where behavior depends on the current clock.

The legacy runner remains the default `npm test` target during the broader #113 transition. This batch removes only the eight migrated registrations and leaves the mixed legacy + Vitest coverage pipeline intact.
